# Betrock++ server for PlayStation 2 (experimental port)

STATUS: compiles and links. NOT yet run on real hardware or in an emulator.
Expect runtime problems (see "Unverified" below).

## Build
1. Toolchain: ps2dev prebuilt release (GCC 15.2.0)
   https://github.com/ps2dev/ps2dev/releases/latest/download/ps2dev-ubuntu-latest.tar.gz
   Extract so that it lives at /home/claude/ps2dev (or edit ps2/env.sh: PS2DEV, ROOT).
2. Toolchain workaround (compiler ICE on __builtin_clzg, used by std::countl_zero/std::format):
   in $PS2DEV/ee/mips64r5900el-ps2-elf/include/c++/15.2.0/bit change the three lines
     #if _GLIBCXX_USE_BUILTIN_TRAIT(__builtin_clzg|__builtin_ctzg|__builtin_popcountg)
   to  #if 0
3. libdeflate: clone https://github.com/ebiggers/libdeflate into ps2/deps/ld, cross-compile
   lib/*.c with mips64r5900el-ps2-elf-gcc -D_EE -G0 -Os, archive to ps2/deps/lib/libdeflate.a,
   copy libdeflate.h to ps2/deps/include/.
4. src/bpp_shared/version.h is generated by CMake normally; create it from version.h.in
   (already included in this archive).
5. ps2/build.sh   (compile all objects, resumable)  then
   mips64r5900el-ps2-elf-gcc -D_EE -G0 -Os -c ps2/ps2_atomics.c -o ps2/build/obj/ps2_atomics.o
   ps2/link.sh    -> ps2/build/betrock.elf

## What was changed
- ps2/ps2_platform.*  : IOP/RPC, filesystem and DHCP network bring-up (ps2_drivers)
- ps2/ps2_atomics.c   : __atomic_* libcalls via interrupt masking (single core)
- ps2/compat/         : force-included shims (flock, put_time, float std::format, replxx stub)
- ps2/typefix.rsp     : makes int32_t == int (newlib has it as long)
- Project edits (all behind PS2 guards or behavior-neutral): Min/Max mixed-type overloads,
  const& for AABB/Material params in world.h/.cpp, PS2 branches in main.cpp, server_socket.h,
  server_console.cpp, hardware.cpp, platforms.h, addon_manager.cpp, addon_impl.cpp.
- GENERATION_PRECISION_DOUBLE is used (doubles are software-emulated on the R5900: slow).

## Unverified

- Where world/config files are written (depends on boot device; USB/memory card/host:)
